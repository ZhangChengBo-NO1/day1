# 💰 智能财务管理系统

一个功能完善的个人财务管理工具，支持收支记录、分类统计、报表生成和数据可视化。

## ✨ 功能特性

- 📊 **记账管理** - 收入/支出录入、修改、删除
- 🔍 **数据查询** - 按日期、分类、类型筛选查询
- 📈 **统计报表** - 月度报表、年度报表生成
- 📉 **数据分析** - 收支趋势分析、分类统计、可视化图表
- 💾 **数据导出** - 支持 CSV、JSON、文本格式导出
- 🔐 **用户权限** - 管理员/普通用户/只读用户三级权限
- 💿 **数据持久化** - SQLite3 数据库存储

## 🚀 快速开始

### 安装依赖

```bash
pip install pandas matplotlib
```

### 运行程序

```bash
# 启动交互式CLI
python main.py

# 运行演示模式
python main.py --demo

# 运行测试
python main.py --test
```

### 默认账号

- **管理员**: `admin` / `admin123`
- **普通用户**: `user` / `user123`

## 📁 项目结构

```
finance_manager/

├── visualizer.py      # 可视化层
├── cli.py             # 用户交互层
```

## 🛠️ 技术栈

- **Python 3.8+**
- **SQLite3** - 数据持久化
- **pandas** - 数据处理
- **matplotlib** - 数据可视化

## 📝 使用说明

### 主菜单

1. **记账管理** - 添加、修改、删除收支记录
2. **数据查询** - 查看交易记录和明细
3. **统计报表** - 生成月度/年度报表
4. **数据分析** - 趋势分析和可视化
5. **数据导出** - 导出数据到文件
6. **系统管理** - 用户和设置

### 收支分类

**收入分类**: 工资、奖金、投资、兼职、红包、其他收入

**支出分类**: 餐饮、交通、购物、娱乐、医疗、教育、住房、水电、通讯、旅游、其他支出

## 📊 报表示例

- 月度收支汇总
- 年度财务总结
- 分类占比分析
- 收支趋势图表
